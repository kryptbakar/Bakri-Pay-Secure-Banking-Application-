# Contributing to Bakri Pay — Secure Banking Application

Thanks for your interest in contributing!

## How to contribute

1. Fork the repository and create your branch from `main`.
2. Make your changes with clear, descriptive commit messages.
3. Test your changes before submitting.
4. Open a pull request describing what you changed and why.

## Reporting issues

- Use GitHub Issues to report bugs or request features.
- For security vulnerabilities, please report privately rather than in a
  public issue.

## Code style

- Keep changes focused and minimal.
- Follow the existing style and conventions of the codebase.

## Questions

Open an issue if anything is unclear.

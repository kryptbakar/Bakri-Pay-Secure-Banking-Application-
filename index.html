About

Bakri Pay is a coursework banking application that models the core of a modern digital bank: user accounts, instant peer-to-peer transfers, virtual card generation, and a financial analytics dashboard. Security is treated as a first-class feature rather than an afterthought — the project layers biometric login, AI-assisted fraud detection, and end-to-end encryption on top of standard banking workflows to demonstrate how a production-grade fintech system should defend user funds and data.

Security Highlights

🔐

End-to-End Encryption

AES-256 for data at rest combined with TLS 1.3 in transit.

🧬

Biometric Authentication

FaceID / fingerprint login alongside traditional credentials.

🤖

AI-Powered Fraud Detection

Real-time analysis of transactions to flag anomalous activity.

🪪

JWT & Session Management

Refresh-token rotation to limit the blast radius of leaked tokens.

🛡️

Transaction Whitelisting

Restrict transfers to pre-approved recipients and devices.

🌐

Hardened HTTP Layer

Security headers and rate limiting to reduce common web attack surface.

Tech Stack

Python Flask PostgreSQL Redis JWT / OAuth 2.0 AES-256 TLS 1.3 React Docker
